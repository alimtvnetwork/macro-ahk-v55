# Version validators must accept the `0.0.0-dev` fallback

## Rule

`version.json` is a build-time artifact regenerated by
`scripts/write-version-from-tag.mjs`. On local dev runs with no tag it holds
`0.0.0-dev`. Any validator, test regex, or assertion that inspects the
resolved version MUST accept the same shape as that script's own SEMVER
pattern: `^\d+\.\d+\.\d+([.-].+)?$`.

A strict `^\d+\.\d+\.\d+$` regex will pass in tag-triggered CI and fail
everywhere else, producing deterministic (not flaky) test failures like the
v5.13.0 fix (prompt-bundle-types SEMVER_RE and macro-controller-recovery).

## Never

- Never hand-edit `version.json` to make a strict regex pass.
- Never re-tighten `SEMVER_RE` in `prompt-bundle-types.ts` to `^\d+\.\d+\.\d+$`.
- Never add a strict-semver assertion for `version.json` without allowing
  the `-dev` / prerelease suffix.
