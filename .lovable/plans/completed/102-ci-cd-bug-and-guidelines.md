# Task 102: CI/CD Bugs and Coding Guidelines

**Status:** Pending
**Created:** 2026-08-08

## Description
This task tracks the resolution of two main objectives:
1. Fixing a CI/CD bug where Playwright E2E tests fail due to a missing IIFE bundle (`macro-looping.js`). 
2. Creating and executing a plan to address widespread coding guideline violations, most notably the 28 `bare fetch` lint errors currently blocking the build pipeline.

## Implementation Steps

### 1. Fix CI/CD Bug (`macro-looping.js` missing)
- **Root Cause:** The `e2e` job in `.github/workflows/ci.yml` downloads the main extension artifact (`chrome-extension-dist`) but fails to download the `macro-controller-dist` artifact generated by the `build-macro-controller` job. The `macro-controller-harness.ts` test utility specifically relies on this standalone dist.
- **Fix:** Add an `actions/download-artifact` step in `ci.yml` for `macro-controller-dist`, extracting it into `standalone-scripts/macro-controller/dist/`.
- **RCA:** Create `.lovable/cicd/issues/15-macro-controller-missing-iife.md` and link it in `.lovable/cicd/readme.md`.

### 2. Address Coding Guideline Violations
- **Immediate Blocker:** Fix the 28 instances of "bare fetch" identified by `no-bare-fetch` lint guard in `package.json`'s prebuild step. These need to be wrapped with the project's standard `httpFailFast()` or `httpFetchOrThrow()` utilities.
- **Systematic Cleanup:** Introduce a phased approach to enforce the 15 Rules (e.g. max 8 lines per function, `is/has` prefix for booleans) across the heavily modified `macro-controller` and `prompt-dropdown.ts` files, splitting large functions into composable helpers.

## Verification
- Run `npm run build` locally to ensure the `no-bare-fetch` lint passes.
- Push to CI/CD and verify that the `e2e` Playwright test successfully discovers `macro-looping.js` and passes.
